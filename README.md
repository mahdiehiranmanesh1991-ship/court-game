# اعتراض دارم! — بازی دادگاه

بازی ماجرایی دادگاهی فارسی (PWA، کاملاً آفلاین) با پرونده‌های خیالی در دادگاه‌های کرمان و مواد واقعی قوانین ایران.
تحقیق کنید، مدرک جمع کنید، شاهدها را بازجویی کنید، روی جمله‌ها «فشار بیاورید» و با مدرک درست «اعتراض!» بزنید.

> ⚠️ آموزشی و سرگرمی است و **مشاوره‌ی حقوقی نیست**. همه‌ی نام‌ها و پرونده‌ها خیالی‌اند.

## اجرا
فایل‌ها ایستا هستند و به هیچ CDN یا سرور بیرونی نیاز ندارند (مسیرها نسبی‌اند؛ در زیرپوشه هم کار می‌کند):
```
cd ..; python3 -m http.server 8080   # سپس http://localhost:8080/court-game/
```
آیفون: در Safari باز کنید ← اشتراک‌گذاری ← Add to Home Screen. بعد از یک بار باز شدن، بدون اینترنت هم کار می‌کند.

## آزمون‌ها
- `npm test` — آزمون‌های واحد موتور (تناقض، قلب‌ها، ذخیره/بارگذاری، امتیاز) و اعتبار و حل‌پذیری همه‌ی پرونده‌ها.
- `PW_DIR=/path/to/playwright-core-parent node tests/e2e.mjs http://127.0.0.1:8080/court-game/` — کروم بدون رابط در اندازه‌ی ۳۹۰×۸۴۴، پرونده‌ی ۱ را تا رأی بازی می‌کند و اسکرین‌شات‌ها را در `screenshots/` می‌گذارد.
- `PW_DIR=… node scripts/icons.mjs` — ساخت دوباره‌ی آیکون‌ها.

## ساختار
- `js/engine.js` — قواعد خالص بازی (بدون DOM)، اعتبارسنج پرونده، ذخیره در localStorage (`eteraz-daram.v1`).
- `js/app.js` — رابط کاربری، دیالوگ تایپی، بنرها، لرزش صفحه، لرزش گوشی (navigator.vibrate، در صورت پشتیبانی).
- `js/art.js` — همه‌ی شخصیت‌ها و پس‌زمینه‌ها به صورت SVG اختصاصی ساخته‌شده با کد.
- `js/audio.js` — جلوه‌های صوتی و موسیقی با WebAudio (بدون فایل صوتی).
- `cases/*.js` — پرونده‌ها به صورت داده. راهنمای نوشتن: `CASES.md`.
- `sw.js` — کش آفلاین؛ با هر تغییر فایل‌ها `VERSION` را بالا ببرید.
- فونت Vazirmatn (مجوز OFL، `fonts/OFL.txt`) به صورت محلی.
